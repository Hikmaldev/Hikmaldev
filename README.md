## Selected projects

### [SOPly — SOP Digitalization](https://github.com/Hikmaldev/SOP-Digitalization) · [Live demo](https://sop-digitalization.vercel.app)

A centralized and versioned SOP library for creating, reviewing, approving, publishing, and auditing company procedures. Includes searchable content, a process-flow diagram editor, role-based access, approval queues, and immutable version history.

**React · TypeScript · Vite · Express · PostgreSQL · JWT · Zod**

### [GudangPro — Warehouse Inventory Management System](https://github.com/Hikmaldev/GudangPro) · [Live demo](https://gudang-pro-brown.vercel.app)

A multi-warehouse inventory system for manufacturing SMEs, designed to replace spreadsheet-based record keeping with stock validation, stock cards, audit trails, and centralized operational data.

**ASP.NET Core Web API · C# · Angular · TypeScript · Entity Framework Core · PostgreSQL · Docker**

### [Clearpath — Report Automation Tool](https://github.com/Hikmaldev/report-automation-tool)

A data-processing tool that turns raw Excel/CSV exports into clean, validated, consolidated reports with charts, flagged-row review, and downloadable outputs.

**Python · Streamlit · Pandas · Plotly · Flask · OpenPyXL**

### [Ruang Belajar — Digital Learning Portal](https://github.com/Hikmaldev/digital-learning-portal) · [Live demo](https://digital-learning-portal-nu.vercel.app)

A lightweight learning portal for non-formal education with bite-sized lessons, auto-graded quizzes, class-code access, and teacher progress dashboards.

**Next.js · TypeScript · Tailwind CSS · Prisma · PostgreSQL · Auth.js**

### [RTHub — Digital RT Dues Management](https://github.com/Hikmaldev/rt-dues-system) · [Live demo](https://rt-dues-system-3zmf.vercel.app)

A community dues platform with resident status management, monthly contribution tracking, public financial transparency, and an admin panel.

**Next.js · TypeScript · Tailwind CSS · PostgreSQL · Zod**
